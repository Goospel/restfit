# T-236 · 돌연변이 하네스가 「전부 생존」이라고 거짓말한다

- **증상**: 돌연변이 실측을 자동화한 스크립트(규칙 하나씩 지우고 테스트를 돌린다)가 18종 **전부**를
  `사살 0 — 공허한 테스트`로 보고했다. 방금 손으로 확인한 테스트들까지 공허하다는 결론이라
  **테스트를 전부 다시 쓸 뻔했다.** 요약 줄만 `NO SUMMARY`로 찍혀 있었다.

- **원인**: 하네스가 `npx vitest run --reporter=basic`을 썼는데 **vitest 4에서 `basic` 리포터가
  제거됐다.** 실행은 `Failed to load custom Reporter from basic`으로 **시작도 못 하고** exit 1로
  끝났고, 하네스는 그 exit 1을 「테스트 실패」로 받아 출력에서 `×` 줄을 찾다가 0건을 세어
  **「아무 테스트도 안 깨졌다 = 돌연변이 생존」**으로 옮겼다. 즉 **실행 실패와 사살 0이 같은 모양**이었다.

- **해결**: `--reporter=basic`을 빼고(기본 리포터가 `×` 줄을 낸다) 다시 돌린다 —
  18종 중 17 사살로 결과가 뒤집혔다. 하네스는 요약 줄(`Tests  n failed | m passed`)을 **함께 찍어**
  「몇 건이 돌았는가」가 로그에 남게 했다.

- **재발방지**: **돌연변이 하네스는 쓰기 전에 「반드시 깨지는 돌연변이」 하나로 자기 자신을 먼저 잰다**
  (이번에도 그 한 건을 단독으로 돌려 보고 나서야 계측기 고장을 알았다). 그리고 **사살 0은 결론이 아니라
  질문이다** — 「내 테스트가 공허하다」와 「테스트가 아예 안 돌았다」가 같은 출력으로 보이므로,
  요약 줄에 **실행된 테스트 수**가 없으면 그 로그는 판정에 못 쓴다(파일 수를 기준선과 대조하는
  T-231과 같은 원리 — **초록도 빨강도 아닌 「집계 없음」을 먼저 감별한다**).
