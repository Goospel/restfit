# T-231 · devDeps 빠진 워크트리에서 vitest 초록불이 거짓말을 한다

- **증상**: 워크트리(`custom-emoji-design-523125`)에서 `npx vitest run`이 **「15 files passed / 301 tests」 초록 요약**으로 끝났다. 그런데 이 레포의 테스트 파일은 19개다 — 화면 테스트 4파일(jsdom 환경)이 **아예 실행되지 않았다.** 워커 기동 실패가 테스트 실패가 아니라 **unhandled errors 4건**으로 요약 아래에 묻혀서, 요약만 보면 전부 통과처럼 읽힌다.

- **원인**: 워크트리의 `miniapp/node_modules`가 예전 시점 것이라 devDependencies(`jsdom`·`@testing-library/react`)가 빠져 있었다. 워크트리는 체크아웃만 새로 뜨고 `node_modules`는 만들 당시 상태로 남는다 — 브랜치를 `origin/main`으로 리셋해 `package.json`이 갱신돼도 설치물은 따라오지 않는다. jsdom 환경을 요구하는 테스트 파일은 워커가 뜨지 못해 **집계에서 통째로 빠진다.**

- **해결**: `miniapp`에서 `npm install` 후 재실행 → **19파일 / 344 테스트**로 정상화.

- **재발방지**: 워크트리에서(특히 브랜치를 리셋·리베이스한 직후) 테스트를 돌릴 땐 ① 먼저 `npm install` ② vitest 요약에서 "passed"가 아니라 **파일 수를 기준선과 대조**한다(이 레포 현재 19파일 — 이 숫자가 줄었으면 뭔가 안 돈 것이다) ③ 요약 아래 **unhandled errors 블록이 하나라도 있으면 통과로 치지 않는다.**
