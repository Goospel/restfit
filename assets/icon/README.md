# 앱 아이콘

**단일 출처는 [`icon.svg`](icon.svg) 하나다.** `png/` 안의 파일은 전부 산출물이니 직접 편집하지 않는다 — 다음 렌더에 덮어써진다.

```bash
powershell -NoProfile -File scripts/render-icon.ps1
```

크기를 바꾸려면 스크립트의 `-Sizes` 만 넘기면 된다(`-Sizes 1024,512`). 원본이 벡터라 어떤 해상도든 그 자리에서 나온다.

## 콘솔에 올릴 파일

| 콘솔 항목 | 파일 |
|---|---|
| **앱 로고** (600 × 600px) | **`png/icon-600.png`** |
| 다크모드 앱 로고 (선택) | **비워 둔다** — 배경이 자체 색이라 라이트/다크 어디서도 같게 보인다 |

⚠️ 콘솔이 크기를 **정확히** 요구한다. 다른 크기를 올리면 거부되거나 리샘플링돼 뭉갠다. 요구 크기가 바뀌면 `-Sizes`에 그 숫자를 넣어 다시 뽑는다 — 원본이 벡터라 어떤 크기든 손실 없이 나온다.

## 무슨 그림인가

**벤치 모서리에서 봉이 힘없이 꺾여 아래로 쏟아지는 덤벨.** 앱 이름이 던진 질문(「홈트가 어렵나?」)에 홈 화면이 *"네, 어렵습니다"* 로 답하는데, 아이콘도 같은 말을 한다.

## 그리면서 배운 것 — 오독 세 번

시안 15개를 거치는 동안 같은 실수를 형태만 바꿔 세 번 했다. 다시 손댈 사람을 위해 남긴다.

- **헤드폰**: 봉이 벤치를 타고 넘어가며 위로 굽으면, 아치 + 양쪽 원판이 정확히 이어캡이 된다
- **웃는 얼굴**: 곡선을 아래로 뒤집으면 이번엔 눈 두 개에 미소가 된다
- **말굽자석**: 봉을 깊게 처지게 하면 봉과 원판이 U자 덩어리로 뭉쳐 수평 봉이 사라진다

셋 다 **좌우대칭**에서 나왔다. 비대칭 구도로 가니 한 번에 풀렸다.

그리고 **덤벨이 덤벨로 읽히는 조건은 「곧은 봉 + 옆에서 본 두꺼운 원판」**이다. 원판을 얇은 원으로 그리면 양쪽에 공 달린 곡선이 되고, 봉을 길게 빼면 온도계가 된다. 봉은 **반드시 원판을 관통**해야 한다 — 바깥 원판에 봉이 안 닿으면 샤워기처럼 보인다.

⚠️ 「봉을 휘면 덤벨이 아니게 된다」는 **평면에서만 참이다.** 3D에서는 명암이 재질을 알려줘서, 봉이 휘어도 원판이 원통 형태를 지키면 「같은 물체가 늘어지는 중」으로 읽힌다. 평면에서 얻은 결론을 3D에 그대로 옮기지 말 것.

## 검수 기준

고칠 때마다 **48px에서 확인한다.** 토스 앱 목록에 뜨는 크기가 그 언저리라, 250px에서 예쁜 것보다 작은 크기에서 안 무너지는 게 중요하다. 배경이 자체 색이라 라이트/다크 양쪽 모두 문제없다(확인함).
