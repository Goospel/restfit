# 벤치 · `bench`

**추천에 늦게 뜨는 기구다.** 맨몸만 가진 사람에겐 +4라 안 보이고, **덤벨을 가진 순간 +12가 되어 나타난다**
(`MIN_GAIN`). 그래서 덤벨을 채운 다음에 오는 것이 순서상 맞다.

공통 규칙(뽑는 법·필드 역할·점검 절차)은 [README](README.md).

## 검색어

```
각도조절 벤치    인클라인 벤치    폴딩 벤치
```

## ⚠️ 이 기구의 함정 — **반드시 각도 조절식**

평벤치로 열리는 운동은 **165개**, 각도 조절식은 **187개**(**+22**).
평벤치를 넣으면 인클라인·디클라인 **34개가 안 열린다** — 사용자가 산 물건이 앱에서 반만 일하는 셈이다.

앱도 둘을 갈라서 안다(`BENCH_OPTIONS` · `effectiveOwned`).

**이름으로 1차로 가른다.** 2026-08-27 실측 — 뽑아 온 18건 중 **4건이 평벤치**였다.

| 이름에 있으면 | 판정 |
|---|---|
| `인클라인` · `디클라인` · `각도조절` | 담는다 |
| `플랫` · `평벤치`뿐 | 뺀다 |
| 셋 다 없음 | **보류** — 상품 페이지를 열어 등판이 세워지는지 본다 |

⚠️ **「벤치프레스」·「멀티」·「14in1」은 각도 조절을 뜻하지 않는다.** 다기능처럼 들려도 이름에 각도가 없으면
확인 전에는 담지 않는다 — 틀리면 사용자가 34개를 못 여는 물건을 산다.

**보류는 상품 사진 한 장으로 갈린다.** 판정 기준은 **「시트와 등판이 갈라져 있는가」** 다 —
갈라져 있고 등판 뒤에 **계단식 조절 홈**이 보이면 조절식, 패드가 한 판이면 아니다.

⚠️ **디클라인 전용도 뺀다.** 패드가 한 판으로 발 쪽만 기우는 싯업 벤치는 각도가 바뀌어도
**등판이 안 세워져** 프레스 계열이 안 열린다.

2026-08-27 실측 — 이름으로 판단이 안 되던 4건을 사진으로 갈랐다: 이고웰 인디클라인 ✅ · 14in1 ✅ ·
멜킨 볼튼(등판이 평평하고 바벨랙이 붙은 제품) ❌ · 아디다스 싯업 디클라인(패드가 한 판) ❌.

## 무게 구간 — **없다**

무게 개념이 없으니 `weight`·`kg`을 **비운다**. 구간이 0개라 **칩도 안 뜨고 배지도 빈다** — 그래서
`note`가 유일한 구분 수단이다. 여기에 적는다:

```
등판 6단계   접이식   최대 하중 300kg   다리 고정 롤러
```
