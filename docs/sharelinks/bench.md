# 벤치 · `bench`

**추천에 늦게 뜨는 기구다.** 맨몸만 가진 사람에겐 +4라 안 보이고, **덤벨을 가진 순간 +12가 되어 나타난다**
(`MIN_GAIN`). 그래서 덤벨을 채운 다음에 오는 것이 순서상 맞다.

공통 규칙(뽑는 법·필드 역할·점검 절차)은 [README](README.md).

## 검색어

```
각도조절 벤치    인클라인 벤치    폴딩 벤치
```

## ⚠️ 이 기구의 함정 — **반드시 각도 조절식**

평벤치로 열리는 운동은 **165개**, 각도 조절식은 **187개**(**+22**).
평벤치를 넣으면 인클라인·디클라인 **34개가 안 열린다** — 사용자가 산 물건이 앱에서 반만 일하는 셈이다.

앱도 둘을 갈라서 안다(`BENCH_OPTIONS` · `effectiveOwned`). 상품이 각도 조절인지 **상세 이미지로 확인**하고 담는다.

## 무게 구간 — **없다**

무게 개념이 없으니 `weight`·`kg`을 **비운다**. 구간이 0개라 **칩도 안 뜨고 배지도 빈다** — 그래서
`note`가 유일한 구분 수단이다. 여기에 적는다:

```
등판 6단계   접이식   최대 하중 300kg   다리 고정 롤러
```
