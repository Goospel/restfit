# 밴드 · `band`

**가장 싸고 가장 안 팔리는 자리일 수 있다** — 값이 낮아 수수료도 낮다. 그래도 원룸에서 실제로 사는 것이라
후보에 남아 있다. 우선순위는 덤벨·벤치 다음.

공통 규칙(뽑는 법·필드 역할·점검 절차)은 [README](README.md).

## 검색어

```
루프밴드    저항밴드    튜빙밴드
```

## ⚠️ 이 기구의 함정 — **긴 밴드가 대부분을 연다**

**종류가 셋인데 앱은 하나로 본다.** 루프(고리형)·튜빙(손잡이형)·평밴드는 쓰임이 다른데 데이터에는
`band` 하나뿐이다. 그런데 **셋이 여는 운동 수가 전혀 같지 않다** — 2026-08-27 실측:

| 종류 | 실제로 되는 운동 |
|---|---|
| 튜빙 · 평밴드 (긴 것) | **20개** — 프레스·플라이·로우·컬·스쿼트·굿모닝 전부 |
| 짧은 루프 (힙밴드) | **3개** — 몬스터 워크 · 힙 어덕션 · 힙 리프트 |

⚠️ **앱은 이 차이를 모른다.** 루프만 산 사람에게도 밴드 운동 23개가 다 열리지만 **실제로 할 수 있는 건 3개다.**
평벤치를 권하면 34개를 못 여는 [벤치의 함정](bench.md)과 같은 구조인데, 이쪽은 앱이 갈라서 알지도 못한다.

**그래서 담는 비율을 뒤집는다.** 검색이 주는 것은 정반대다 — 2026-08-27 실측 47건:

```
여는 운동:  긴 밴드 20  :  루프 3
검색 결과:  긴 밴드 19  :  루프 22     ← 튜빙 12 · 평밴드 7 · 풀업 보조 4 · 밴드 아님 2
```

그대로 담으면 **목록의 절반이 3개짜리 물건**이 된다 — **긴 밴드를 앞에, 루프는 대표 몇 개만.**

- **세트 상품이 많다.** 강도별 5개입이 흔하다 — `note`에 `5종 세트`를 적는다
- **강도(파운드·컬러)는 앱이 안 쓴다.** 온보딩에서 밴드 강도를 묻지 않기 때문이다.
  예외는 **세라밴드** — 색이 곧 강도인 표준(옐로우 < 레드 < 그린)이라 이름에서 색을 떼면 셋이 구분되지 않는다
- **밴드가 아닌 것이 섞인다.** 스텝퍼 전용 부속·8자 스트레칭밴드처럼 **단독으로 근력 운동이 안 되는 것**은 뺀다
- **검색어 셋이 서로 겹친다.** 같은 상품이 두세 메모에 나온다(실측 52건 → 고유 47건) — 코드 부분(`_m/` 뒤)으로 대조한다

## 무게 구간 — **안 쓴다**

`weight`·`kg`을 **비운다.** 강도 축을 필터로 세우려면 온보딩부터 고쳐야 하는데, 밴드 강도 표기는
브랜드마다 제각각(파운드·컬러·단계)이라 통일이 안 된다. 구간이 0개라 **칩도 배지도 없고**, `note`가 유일한 구분 수단이다:

```
루프 5종 세트   튜빙 · 손잡이   천 소재 · 안 말림   문틀 고정 포함
```

⏸ 링크를 채우면서 「강도로 나눌 만한가」가 보이면 그때 다시 판단한다. 지금 미리 축을 만들지 않는다.
