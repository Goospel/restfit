# 풀업바 · `pullupBar`

문틀에 거는 철봉. 등 운동을 여는 거의 유일한 저가 기구다.

공통 규칙(뽑는 법·필드 역할·점검 절차)은 [README](README.md).

## 검색어

```
문틀철봉    철봉    도어짐
```

## ⚠️ 이 기구의 함정 — **「풀업바」로 검색하지 않는다**

「풀업바」로 검색하면 **푸쉬업바(팔굽혀펴기 손잡이)가 섞인다.** 생김새도 이름도 비슷한데 전혀 다른 물건이고,
**푸쉬업바를 쓰는 운동은 데이터에 0개**라 넣어도 화면에 안 뜬다. 실제로 한 번 섞여 들어와 걸러냈다.

담기 전에 **문틀에 거는 물건이 맞는지** 상품 이미지로 확인한다.

## 무게 구간 — **없다**

무게 개념이 없으니 `weight`·`kg`을 **비운다**. 칩도 배지도 안 뜬다 — 고르는 기준은 **설치 방식**이라
그것을 `note`에 적는다:

```
압착식 · 타공 없음   나사 고정   거치식 · 문틀 위 걸이   최대 하중 150kg
```
