# 오늘 할 운동 추천 알고리즘 — 리서치 (2026-08-27)

병렬 리서치 3건(과학 문헌 / 프로필 변수 유효성 / 경쟁 앱 비교)의 결과와 교차 대조.
설계는 [2026-08-27-workout-reco-design.md](2026-08-27-workout-reco-design.md)가 잇는다.

## 교차 대조 요약 — 세 보고서가 일치하는 것

1. **같은 근육군 재훈련 간격 48~72시간** — 문헌(근단백 합성 24~48h, 고볼륨 ~72h)과 실무(Fitbod 회복 모델, RR·StrongLifts의 격일 전신)가 일치.
2. **"목표 반복 달성 → 난이도 승급" 사다리** — 문헌(double progression, 부하·반복 progression 동등 실증)과 실무(RR 3×8 승급, StrongLifts +2.5kg, GZCLP 볼륨 달성 증량)가 일치.
3. **복합 운동을 앞에** — Fitbod(Focus 앵커)·GZCLP(T1→T3)·현행 `pickRoutine` 정렬이 이미 같다.
4. **성별·키는 처방을 바꾸지 않는다** — 메타분석(상대 근비대·하체 근력 남녀 동일)과 실무(종목 선택에 성별·체중을 쓰는 앱 없음)가 일치. 키 단독 근거는 미발견.
5. **주간 볼륨이 같으면 빈도·분할은 무차별** — 볼륨이 하드 목표, 빈도는 소프트.
6. **실패지점까지 갈 필요 없음(RIR 2~3)** — 단 맨몸 고반복은 실패에 가깝게 가야 자극 유지.

## 교차 대조 — 상충 지점

| 쟁점 | 한쪽 | 반대쪽 | 비고 |
|---|---|---|---|
| 온보딩 체력 테스트 | 프로필 리서치: 첫 세션을 푸시업 최대 개수 테스트로 (질문 0개 증가, norm 표준화됨) | 경쟁 앱: Freeletics는 테스트를 **폐지**하고 자가평가 + 매 세션 피드백으로 전환. 홈트 근력 앱에서 온보딩 테스트는 표준이 아님 | 설계에서 판단 |
| 휴식 길이와 근비대 | Schoenfeld 2016 RCT: 3분 > 1분 | Bayesian 메타 2024·2025: 훈련자에서 차이 trivial | 60~120초면 안전, 60초 미만은 피함 |
| 빈도 | 2016 메타: 주2회 > 1회 | 2019 재분석: 볼륨 등화 시 무차별 | 빈도는 소프트 제약 |

## 보고서 1 — 과학 문헌 (ACSM·메타분석)

### 목적별 세트 처방

| 목적 | 반복 | 세트/운동 | 세트 간 휴식 | 근육군당 주간 세트 | 근육군당 주 빈도 |
|---|---|---|---|---|---|
| 근력 | 1~6회 (고부하 ≥80%1RM 상당 = 어려운 변형) | 2~4 | 2~3분(복합), 1~2분(보조) | 4~10세트면 충분 | 주 2회+ |
| 근비대 | 6~12회 핵심, **5~30회 전 범위 유효**(실패 근접 조건) | 3~4 | 60~120초 (90초 기본) | **주 10세트+**(용량반응, ~20까지 점증) | 주 2회 |
| 근지구력·체지방 보조 | 15~25회 | 2~3 | 30~90초 | 근비대와 동일 틀 | 주 2~3회 |

- RIR 2~3이면 충분(ACSM 2026). 맨몸 저부하 고반복은 실패 근접(RIR 0~1) 요구.
- 템포는 0.5~8초/회면 동등 — 강제 불필요.

### 경력별 조정

| | 초급 | 중급 | 상급 |
|---|---|---|---|
| 세션 빈도 | 주 2~3회, **전신** | 주 3~4회, 전신 또는 상/하체 | 주 4~5회, 분할 가능 |
| 강도 | 쉬운 변형, ~60%1RM 상당에서 최대 효과 (Rhea 2003) | 8~12RM 상당 | 1~12RM 스펙트럼, 80% 중심 |
| 세트/운동 | 1~3으로 시작 | 3 | 3~6 |
| 진행 속도 | 거의 매 세션 | 주 단위 | 느림 |

- 전신 vs 분할: 주간 볼륨 같으면 동등. 초보 전신의 실익 = 적은 세션으로 빈도 2~3회 확보 + 학습 빈도 + 결석 피해 분산.

### 회복

- 같은 근육군 재훈련 **≥48시간** (고볼륨·미련자 ~72h). 24시간 미만은 하드 컷.

### 맨몸 점진적 과부하 사다리

1. **반복 증가** (목표 대역 상단을 전 세트 달성하면 →)
2. **난이도 변형 상향** (하단 반복으로 리셋) — 부하 progression과 반복 progression은 동등 실증 (Plotkin 2022 PeerJ)
3. 반복 25~30회 초과 시 근비대 효율 급락 → 난이도 상향 강제
4. 맨몸 유효성 직접 근거: 푸시업 vs 벤치프레스 동등 RCT 3건 (Kikuchi 2017 · Kotarsky 2018 · Thomas 2017)

### 주요 출처

ACSM 2009 (PMID 19204579) · ACSM 2026 (MSSE 58(4):851-872, PMC12965823) · Schoenfeld 볼륨 메타 2017 (PMID 27433992) · 부하 메타 2017 (PMID 28834797) · Repetition Continuum 2021 (PMC7927075) · 빈도 메타 2019 (PMID 30558493) · 템포 메타 2015 (PMID 25601394) · Rhea 2003 · Plotkin 2022 (peerj.com/articles/14142) · Helms RPE 2018 · Kikuchi 2017 · Kotarsky 2018 (PMID 29466268) · Grgic 실패 메타 2021 (PMID 33497853)

## 보고서 2 — 프로필 변수 유효성

### 판정표

| 변수 | 판정 | 요지 |
|---|---|---|
| 운동 경험 | **바꾼다** | 훈련 상태가 볼륨·강도·빈도를 바꾸는 유일한 공인 축. ACSM 분류: 미훈련/공백 → 초급, 6개월+ 일관 훈련 → 중급 — **질문 1개로 구현 가능** |
| 자가 체력 테스트 | **바꾼다** | 시작 난이도 배정의 가장 직접적 근거. 푸시업 norm 표준화(연령·성별별). 단 경쟁 앱 분석과 상충 — 위 상충표 |
| 부상 이력 | **바꾼다** (종목 제외 필터) | 과거 부상 = 재부상 최강 위험인자. 부위 → 주동근·협응근 매핑으로 제외 |
| 나이 | 65세+만 분기 | NSCA·WHO: 고령자만 밸런스 요소 추가·고충격 제외·10~15회 저강도 시작. 이하는 norm 보정용 |
| 몸무게 | **맨몸 한정 바꾼다** | 푸시업 = 체중의 69~75% 지지 (Suprak 2011) — 체중이 곧 부하. BMI↑ = 부상 확률 선형 증가, 고충격(점프·플라이오) 스왑 근거 |
| 성별 | 거의 안 바꿈 | Roberts 2020 메타: 상대 근비대 남녀 동일(ES 0.07), 하체 근력 동일. PeerJ 2025·Sci Rep 2021 일관. norm 해석에만 필요 |
| 키 | 거의 안 바꿈 | 처방을 바꾼다는 문헌 미발견. BMI 계산용인데 몸무게 단독 컷오프로 대체 가능 |
| 가용 시간 | 간접 | 짧으면 복합 다관절 압축 (Iversen 2021 "No Time to Lift?": 근육군당 주 4세트 최소선 + 밀기/당기기/하체 프레스 각 1) |
| 주당 일수 | 간접 | 볼륨 같으면 빈도 무차별 — 스케줄링 변수 |

### 추천 최소 질문 집합

- **질문 +2**: ① 경험("최근 6개월, 주 2회 이상 꾸준히 운동했나요?") ② 불편 부위(없음/무릎/어깨/허리/손목 멀티)
- **질문 없이**: 체중은 선택 입력(스킵 가능), 시간은 세션 시작 시 프리셋 토글
- **받지 말 것**: 성별, 키, 나이(선택), 주당 일수
- 온보딩 필드 1개당 완료율 약 3~7% 감소(업계 데이터, 학술 아님 — 방향성만)

### 한계

- 부상 부위 제외 → 재부상 감소는 위험인자 근거로부터의 추론(직접 RCT 미발견)
- ACSM 초/중급 경계 6개월은 사실상 단일 출처(업계 표준으로 널리 채택)

## 보고서 3 — 경쟁 앱·실무 방법론

### 종합 비교

| | 온보딩 | 종목 선택 | Progression | 실패 처리 |
|---|---|---|---|---|
| Fitbod | 목표·경험·기구·최근 근육 | 회복% + 적합도 + 피드백 + 분할 + 기구 5요소 | Epley 1RM 추정 → %존 | 무거운 날/가벼운 날 주기화 |
| Freeletics | 자가평가·목표·기구·스케줄 (**체력 테스트 폐지**) | 클러스터 초기화 + 피드백 | 매 세션 난이도 설문 | "너무 어려움" 누적 → 하향·대체 |
| StrongLifts | 없음 | 고정 5종목 A/B | 전 세트 성공 → +2.5kg | 3연속 실패 → -10% |
| GZCLP | 5RM만 | 고정 티어 T1/T2/T3 | 볼륨 달성 → 증량 | **세트 스킴 강등**(무게 유지) |
| r/BWF RR | 없음(할 수 있는 단계 자가 선정) | 고정 슬롯(당김/밈/하체/코어) | **3×8 달성 → 사다리 다음 단계** | 단계 하향 |

- Fitbod 회복 모델: 세트 기록에서 근육군별 피로도 산출, 48~72h 실전 권장. 핵심 장치는 전부 명시적 규칙/공식 — 규칙 기반 이식 가능.
- 성별·체중을 종목 선택 로직에 쓰는 앱: **확인된 범위에서 없음**.
- RR 페어링은 버전 간 불일치 실측(Antranik 구판 vs 현행판) — 현행판(풀업+스쿼트 / 딥+힌지 / 로우+푸시업) 기준.

### 훔칠 규칙 TOP 5

1. **근육 회복 게이트** — 최근 48~72h 내 때린 주동근은 후순위/제외. 세트 기록이 이미 있어 역산만 하면 된다.
2. **3×8 달성 → 난이도 승급** — 데이터의 난이도 3단계에 그대로 매핑. 무게 종목은 "전 세트 성공 → +2.5kg".
3. **실패 시 스킴/단계 강등** — 2~3세션 연속 후퇴 시 무게 -10% 또는 목표 반복 하향 제안.
4. **복합 1~2개 앵커 + 고립 채우기** — 복합/고립 플래그로 구현.
5. **세션 종료 난이도 1문항** — 쉬움/적당/힘듦. 적게 묻고 매 세션 1비트씩 학습 (Freeletics가 테스트를 폐지한 이유).
